Since time travel is not needed, I started from the point in the React tic-tac-toe tutorial right before the time travel implementation, so there is no Game function. I keep the same winner logic as before.

I also added the function countPieces outside the Board function in case some other function might call it in the future. The purpose of this function is to take an array that represents the board and count how many X's or O's there are, since the count determines whether the player should only place marks down or if they should move the piece.
In Board, I added: const currentMark = xIsNext ? 'X' : 'O'; which will be passed as the second argument to countPieces.
I also added: const currentCount = countPieces(squares, currentMark); which calles the countPieces function so that later if can be checked if pieces should only be placed on the board or if existing pieces need to be moved.
Lastly, I added const isPlacementPhase = currentCount < 3; because when a player has less than 3 of their mark on the board, they can put down more.
I added the function indexRowColumn because the squares 0-8 correspond to coordinates on the board, which instead of hardcoding the rows and columns, I can use Math.floor on the division of the index and 3 to get the row and index % 3 to get the column, where rows are 0-2 top to bottom and columns are 0-2 left to right.
